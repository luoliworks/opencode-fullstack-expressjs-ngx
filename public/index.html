Fallback frontend (Express /public)

The Angular production build was not found, so Express is serving this fallback page instead. To switch to the Angular frontend:

  1. cd frontend-ngx
  2. npm install
  3. npm run build
  4. Restart this server

API endpoints

  • GET /api — API index, lists available endpoints
  • GET /api/hello — Sample endpoint → { "message": "Hello, World!" }
  • GET /api/articles — List articles, newest first (?page=&pageSize=[&status=] for paging; /api/articles/slug/:slug and /api/articles/:id for single reads)
  • GET /api/users — List users, admin only (/api/users/:id for GET/PATCH/DELETE)
  • POST /api/login — Login with { username, password } → { token, user }
  • GET /api/setup — { needsSetup }, true when the admin account still needs bootstrapping
  • GET /health — Health check → { "status": "ok" }
